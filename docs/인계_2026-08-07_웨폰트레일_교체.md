# 인계 문서 — Haru 무기 트레일을 X-WeaponTrail 에셋으로 교체

**작업일**: 2026-08-07 · **브랜치**: `develop-JS` · **작업자**: KimJeSeoung

`Assets/Scenes/JS/Animator_Effect.unity` 씬의 Haru 프리팹에 **직접 만들어둔 무기 트레일 오브젝트**를
에셋 스토어 패키지 **X-WeaponTrail**(`Assets/ExternalAssets/XWeaponTrail`)로 교체하려는 작업입니다.
**아직 교체를 시작하지 못했고, 대상 오브젝트조차 특정하지 못한 상태에서 중단되었습니다.**

| 교체 작업 | **미착수** |

## 2. 지금까지 확인한 것

- 씬 파일(`Animator_Effect.unity`)을 텍스트로 grep했지만 `TrailRenderer` 컴포넌트나 이름에 "Trail"이
  들어간 GameObject를 찾지 못했다. Prefab 오버라이드 특성상 이름이 비어 있는(`m_Name: `) 항목이 많아서
  텍스트만으로는 계층 구조를 재구성하기 어렵다.
- 씬에서 유일하게 발견한 `ParticleSystem`은 `Speed`라는 이름의 오브젝트(이동 속도감 표현용으로 추정, 무기
  트레일과 무관해 보임). 무기에 달린 것인지는 미확인.
- `Assets/Scripts` 전체에서 "Trail"/"검기"로 grep한 결과, 무기 트레일을 토글하는 전용 스크립트는
  **존재하지 않는다.** `PlayerCombat.cs`의 "검기"는 투사체(원거리 판정) 기능이라 이번 작업과는 다른 것이다
  (`ProjectileSlot`, 슬롯 키로 발사하는 근접 스킬 투사체) — 혼동 주의.
  → 즉 지금 쓰고 있는 트레일은 **코드로 켜고 끄는 게 아니라 씬/프리팹에 순수 비주얼 오브젝트로 배치되어
  있고, 아마 애니메이션 커브나 항상 On 상태로 재생되는 방식**일 가능성이 높다. 다음 세션에서 에디터로
  직접 열어 확인 필요.
- `Assets/ExternalAssets/XWeaponTrail/Scripts/XWeaponTrail.cs` 코드를 읽었다. 핵심 필드:
  - `PointStart` / `PointEnd` (Transform) — 트레일 폭을 결정하는 두 기준점. 보통 무기의 칼끝/칼자루에 배치.
  - `UseWithSRP` — **URP 프로젝트이므로 반드시 체크 필요** (Camera.onPreRender/onPostRender 콜백은
    Built-in RP 전용이라 URP에서 안 켜면 안 그려진다). 인스펙터의 "Use With SRP" 항목.
  - `MyMaterial`, `MyColor`, `MaxFrame`, `Fps`, `Granularity` — 트레일 길이/잔상 프레임 수/부드러움 튜닝.
  - `Activate()` / `Deactivate()` / `StopSmoothly(fadeTime)` — 코드에서 트레일 on/off를 제어할 때 쓰는
    공개 API. `OnEnable`/`OnDisable`에서 자동으로 Activate/Deactivate가 걸리므로, 단순히
    `gameObject.SetActive()`로도 켜고 끌 수 있다.
  - `Editor/XWeaponTrailEditor.cs`에 인스펙터 커스텀 버튼 2개(Documentation/Unity Forum)가 있는데
    이건 외부 링크 버튼일 뿐 기능과 무관하다(이전 대화에서 이미 확인함).

## 3. 다음 세션에서 제일 먼저 할 일

**Unity 에디터에서 `Animator_Effect.unity` 씬을 열고, Hierarchy에서 Haru 프리팹 아래 트레일
오브젝트를 직접 찾아 이름/경로를 확인하는 것부터 시작.** (텍스트 grep으로는 한계가 있었음)

확인해야 할 것:
1. 트레일 오브젝트의 정확한 Hierarchy 경로 (예: `Prefab Character/Haru/.../hand_r/Weapon/무기이름/Trail계열이름`)
2. 어떤 컴포넌트로 구현되어 있는지 (Particle System 트레일 모듈? Trail Renderer? 커스텀?)
3. 무기 메시의 칼끝/칼자루 트랜스폼이 이미 따로 있는지 (X-WeaponTrail의 `PointStart`/`PointEnd`에 그대로
   연결할 수 있으면 작업이 빨라짐 — 없으면 빈 자식 오브젝트 2개를 새로 만들어 배치해야 함)

확인 후 교체 절차(예상):
1. 기존 트레일 오브젝트 비활성화 또는 제거(바로 삭제하지 말고 우선 비활성화 권장 — 비교하며 튜닝하기 위함)
2. `X-WeaponTrail.prefab`(또는 `XWeaponTrail` 컴포넌트)을 무기 오브젝트 자식으로 추가
3. `Point Start`/`Point End`를 무기의 칼끝·칼자루 트랜스폼에 연결
4. **`Use With SRP` 체크** (URP 프로젝트이므로 필수 — 안 하면 아무것도 안 그려짐)
5. `My Material`에 트레일용 머티리얼 연결, 색상·페이드 시간 튜닝
6. 플레이 테스트로 기존 트레일과 비교
